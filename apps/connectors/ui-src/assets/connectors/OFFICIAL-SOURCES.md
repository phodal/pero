# Connector logo sources

These 96 × 96 PNGs were converted from marks published by the named projects,
vendors, or standards bodies on 2026-09-27. The conversion preserves the mark
and aspect ratio, except that `ansys.png` crops the A mark from Ansys's own
header SVG. `pylabrobot.png` uses the project's official GitHub organization
avatar. Bundling avoids remote image requests from the settings window.

## Public-data catalog additions (2026-10-19)

96 × 96 PNGs resized from the official favicon, touch icon, or compact organization mark. Aspect ratio is preserved on a transparent canvas. `paleobiology.png` recolors the site's white seal to near-black so it stays visible on the light icon plate. `datacite.png` keeps the symbol from the organization avatar and drops the wordmark, which does not fit the square slot. `ncbi.png` is the NLM chevron served by both PubMed and ClinicalTrials.gov. NOAA climate, marine, and space-weather cards share `noaa.png` because the space-weather favicon was a 16px mark. These identify the associated project or agency, not an endorsement of the community MCP server.
