# Reproducible memory recall and provenance evaluation

The research issue has no frozen query denominator or comparable correction,
validity, source withdrawal and deletion receipts. The existing #162 trial already
establishes Engram's external process, per-workspace directory isolation and
optional admission. It is retained as historical evidence, not rerun as new work.

At Pero 561e2850157f3a0b406289dba9488206188451ab, sidebar Session Search filters
titles; it is not full transcript search. Insights folds short excerpts and tool
status, not complete results. Existing fstools.Search (search_files) can search
an explicitly exported transcript directory. The experiment must name this
limitation rather than invent an implemented cross-session search product.

Scope: synthetic records only, fixed questions, exact source refs/hashes, actual
fstools.Search versus pinned external Engram, and an evaluation-only deterministic
source/validity gate. No real user journals or memory; no runtime composition,
new notes database, default background job, paid model or external deployment.
Review fixed Hindsight, LangMem and Graphiti source/license/dependency boundaries.
LLM extraction, Dreaming and Wiki quality remain unmeasured without a model run.

Canonical record for #161; #162's existing record and implementation remain separate.

## Bounded PoC delivered

The [evaluation and decision record](../fitness/memory-recall-evaluation-2026-11-11.md)
links runnable fixtures, actual-process runner, source pins and compact measured
receipts. Two fresh isolated runs produced identical deterministic outcomes:
15 synthetic records, 25 fixed questions, 12 positive expectations. Both native
search_files and external Engram retrieved all expected IDs on 11/12 positive
questions; both missed the semantic paraphrase. The authored source/validity
gate matched 24/25 native and 23/25 Engram expectations; Engram's additional
stale-source case abstained until rebuild. These are not model answer scores.

Correction/history, condition conflict, verification support, source readback,
scope isolation, revocation/deletion, restart and rebuild have executable
receipts. Existing fstools/nativetools race tests and the new value-level tests
passed. Hindsight, LangMem and Graphiti have fixed official source/license
reviews; they are not executed comparison arms. No model calls were made.

Decision: reuse provenance, validity and withdrawal contracts only; retain the
existing default-off external Engram boundary. No new service, persistence owner,
worker, runtime dependency or UI was added. Broader #161 remains open for a real
equally budgeted model comparison, Dreaming/Wiki quality and generalization.
