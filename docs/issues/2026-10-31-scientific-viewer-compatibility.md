# Scientific Viewer on the independent Pero Host

The original Scientific Viewer package cannot install while its declared Agent,
Workspace and Harness contracts are refused. Its absolute Point UI URLs also
need to resolve PDF workers/fonts inside the installed App assets; rewriting or
removing its permissions would hide the failures rather than preserve the workflow.

The bounded repair keeps original App code unchanged. Point SDK requests project
onto Pero-owned Sessions, approvals, journal and workspace; original Node data,
PDF evidence checks and review output integrity rules remain authoritative.

Acceptance: real Pero install/render, all bundled examples, local PDF quote and
figure evidence, review generation through the existing ACP seam, same-request
reconciliation, cancellation, retry, explicit Session load after restart, original
review saving/export and exact Session selection. Real-provider answer quality,
scientific correctness and signed/cross-platform release acceptance remain separate.
