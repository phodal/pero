# Skills 市场：发现、安装与按需使用

研究者需要按实际任务发现 skill，核查来源和条件，安装后在普通聊天中选择使用，并能管理更新、回退、停用和移除。市场不能把“目录已解析”展示成“科研运行已验证”。本记录是 [上游 #156](https://github.com/phodal/pero/issues/156) 的本地活动记录。

## 已处理问题

- 首屏由物理分类顺序决定，集中展示 AI 条目。现按研究任务或名称排序，逐条展示真实用途和分类；分类器先看技能名称和方法，父集合路径不再覆盖用途。16 项中文编辑说明按身份及固定版本匹配，原始描述保留。
- `knowledge-distillation` 的静态 `author` 被当作执行字段拒绝。适配器允许静态描述元数据，继续拒绝未知执行字段、来源 hooks 和安装器。
- 全局 busy 和获取锁使一项获取阻塞其他项。获取进程、取消和 UI 状态按 skill 拥有，发布时合并到最新安装记录；失败或取消保留已有版本。
- 同仓库逐项安装的笼统 Git 错误不能稳定复现为单一网络原因。现按固定提交获取选中目录和显式资源，避免每项下载整库；错误显示获取阶段和脱敏原因。五个 AER 固定来源和知识蒸馏已在 Windows 实际获取并核对摘要。
- 安装后普通聊天选择器未列出未启用的技能。现列出当前 profile 的实际安装版本，解析正文和资源并冻结引用；全局启用与一次聊天的显式引用分开。
- 用户确认新的 HTML 交互后，已接入横向列表、共享详情抽屉、独立安装任务和新会话草稿。产品右上角不显示开发 PR/issue 链接。
- 正常重启仍显示旧 UI：受管 App 更新因系统盘仅约 8 MB 可用而失败。Skills 的无用阅读器占约 142 MB，原子替换保留旧页。builder 排除该载荷后发布树约 0.83 MB；日常 profile 重启观察到新 UI，安装状态摘要及原有 3 项记录保持一致。

## 交付范围

32 个固定来源快照、1,985 个候选路径、1,766 个去重条目和 13 个中文分类。Host profile 拥有安装与版本；Go 复用现有 Git/插件准入；工作台 App 只调用声明的 `skills` capability。普通 Pero 会话绑定快照，App 会话维持自己的声明边界。
