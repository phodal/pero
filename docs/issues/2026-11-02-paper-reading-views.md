# Paper reading views lose layout and conflate source inspection with typesetting

The Native preview's TeX disclosure embeds the complete source inspector in a
narrow absolute-positioned popup. Expanding its split view introduces nested
scrolling and can displace the reading header. Closing the popup alone does not
restore the header; returning to the library and reopening the paper does.

The existing Read view is derived from official HTML. Downloading a TeX archive
does not typeset it, and the source inspector must not imply otherwise. The user
requested one reading toolbar with Read/PDF/TeX/Original tabs, and explicitly
selected a typeset TeX preview with source inspection as a secondary action.

Repair keeps original PDF evidence separate from locally compiled TeX output,
retains the existing PDF viewer and source acquisition owners, and binds compiled
previews to the exact source archive, entry file and engine. Compilation failures
must remain visible, with source inspection and explicit retry available.

Acceptance uses the user's cached arXiv 2610.27435v1 source, including ailab.cls,
figures, author affiliations and contribution macros; a substitute original PDF
is not a successful TeX preview. Check one-row chrome, tab and keyboard switching,
PDF/TeX state preservation, narrow/dark layouts and recovery from compile errors.

Resolved locally on 2026-11-03: the four representations share a single stable
header; TeX uses a real Tectonic compilation, and source inspection opens in a
bounded SDK Dialog with resizable/stacking panes. Escape restores the existing
preview. Generated bytes remain separate from original PDF evidence.

Follow-up: Native's default CSP/navigation policy initially blocked the Original
iframe. Explicit manifest frame origins now connect through Host to both shells;
Paper declares arXiv only. Native was rebuilt and its embedded official page was
visually verified. External documents do not receive the App SDK IPC authority.

The user's actual source compiled to 38 pages and was inspected in Native
Preview, including its custom class, author macros, formulas and figures.
Browser checks covered switching, separate PDF/TeX state, light/dark layouts,
490px width and source-dialog dismissal. Automated checks and remaining
platform/HTML-parser limits are recorded in
[Paper reading views](../fitness/paper-reading-views.md).
