Read your first paper

Import a PDF and save an annotation. When you want further analysis, send a question and follow the citations back to the source.

Import and save a highlight

Choose a PDF with selectable text. On first use, prepare the App environment.

  1. Open Papers from the sidebar and choose Add papers → PDF → Import PDF, or drop the file into the Paper window.
  2. Select a sentence and choose Highlight. Open Annotations from the PDF context menu and inspect the saved location and quotation.
  3. Return to the library and reopen the paper. Confirm the annotation still points to the right page. Paper saves annotations separately and retains the original PDF.

This step requires no model. Text selection and search rely on the existing PDF text layer. If text is unavailable, use Capture area from the PDF context menu to save the location of a figure or table for review.

Ask an Agent about a passage

  1. For the built-in Agent, open Settings → Built-in Agent and enter the API URL, model, and key. External Agents use their own sign-in flows. Full-text PDF research requires an Agent with HTTP MCP support. See the Agent setup guide.
  2. Click Ask AI in the reader, or select text and choose Discuss selection. Review the draft and any attached passage, then send. Your model provider may receive the question and selected text.

Follow citations to the source

  1. After the report is saved, click the clock icon labeled Research record in the reader toolbar and open the report.
  2. Click a citation and read the surrounding passage. When a quotation has multiple matches, choose the location relevant to the claim.
  3. Compare the claim with the source and review any open questions. Use Continue from here to draft a follow-up and send it when ready.

A citation locates a source passage. Check whether the passage supports the claim and whether the method applies to your own work.

Troubleshooting

  • Agent fails to start or sign in. Check your Agent choice, credentials, and the error shown in the conversation. After signing in, review and resend the question.
  • Full-text search returns no matches. Try the paper's terminology, narrow your question, or select a known passage in the reader. An empty result describes the current search.
  • A study stops before submitting a report. Open the saved research record, review its findings and gaps, then choose Continue research.
