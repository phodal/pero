Read and research papers

Import, annotate, and search a public PDF, then send a focused question to an Agent. Use the saved report to check citations, record gaps, and export evidence.

First launch in the November 12 preview

We followed this tutorial with the v0.1.0-dev.20261112 macOS Apple Silicon Electron package. In a clean profile, Prepare environment returned to Environment not ready. The Host reported that the required paper-autoresearch plugin was missing from the package. Python preparation had yet to begin.

For the rest of the walkthrough, we installed the plugin from the same release tag into the isolated profile using the packaged Host’s plugininstall action. After restarting the original app and choosing Prepare environment, dependency installation finished and the library opened automatically. Release-tag Host plugin installation · Matching plugin

Import your first paper and save a highlight

Open Papers in the desktop workbench. On first use, prepare the App environment if prompted. This walkthrough uses the public preprint Meta-Harness (arXiv:2603.28052v1). You can also use a PDF you have permission to access with selectable text.

  1. Download the versioned example PDF. In the library choose Add papers → PDF → Import PDF, or drop the file into the Paper window. Paper opens the saved PDF. Importing a byte-identical file reopens the existing record.
  2. On the first page, find the sentence containing agentic proposer in the abstract. Select text within that page. Enter a note if useful, such as “Which previous results can the proposer see?” Then choose Highlight.
  3. Right-click the PDF and choose Annotations. Check the quotation, page number, and note. Return to the library, reopen the paper, and choose the annotation’s page number. You should return to the saved page and region.

Expected result. Save the input as Meta-Harness-v1.pdf and the library shows Meta-Harness-v1. The reader shows 1 / 26, with one annotation pointing to page 1. Reopen it and select the page link to return to the highlighted passage and saved note. This flow needs no model account or API key.

Choose a reading view and organize annotations

  • PDF gives you the original pagination, figures, and citation locations. Choose Page text from the PDF context menu to read the extracted text for the current page. Text selection depends on the file’s existing text layer.
  • Read displays imported text or prepared structured full text. For a supported arXiv source, review the fixed version and authorize its official HTML to retain sections, equations, and tables. HTML and PDF preserve their own source locations.
  • TeX builds a reading preview from an approved same-version source archive. The current compiler path requires macOS and Tectonic. The first build can need dependency downloads. The preview and the original PDF have separate identities and pagination. TeX reading and diagnostics

For a scanned page, equation, or figure, choose Capture area, drag over the region, and confirm the image annotation. Choose Annotations → Add to matrix and enter a comparison field such as “Sample size” or “Metric.” The matrix page link opens the original region. Check values and units against headers, captions, and surrounding text.

Find saved evidence and discover more papers

Search your own library

Return to the library and submit agentic proposer in Search saved text. The release returned one paper and 12 passages. The first hit pointed to references on page 14. Scroll to the PDF Page 1 result with the abstract passage. Open it and check that the reader shows 1 / 26. Expand Snapshot details to check the passage and file digest. This search runs locally without starting an Agent.

Find sources through public literature services

  1. Use Add papers to search by title or keyword, or read a known paper ID. The selected public literature providers receive the search terms.
  2. Check the title, authors, date, and version before saving. Identify whether you are reading Full text, an Abstract, or a Third-party report. Open the appropriate original before evaluating methods, data, or metrics.
  3. Choose Discover on a saved paper and select Related papers, References, or Citing papers. If prompted to confirm the source, compare the OpenAlex candidate’s title, authors, and year. Save useful candidates and treat relationship results as leads to check.

To inspect a public page that links papers, code, and data, use Add papers → Research URL with its HTTPS address. Save references first, then separately review and confirm any offered file downloads. Research URL import and resource limits

Ask a question you can check against the source

  1. Prepare a model using the Agent setup guide. Set the API URL, model, and key for the built-in Agent, or complete an external Agent’s sign-in flow. Full-PDF research requires an Agent with HTTP MCP support.
  2. Choose Discuss selection on an excerpt from the example, or choose Ask AI in the reader. Review the draft and attached excerpt. Remove unrelated text. Hide the conversation for full-width reading, or toggle it with Cmd/Ctrl+J.
  3. For a question that needs material beyond the selected excerpt, open Research settings, select one to five saved PDFs, and enable Search full PDF text. Sending freezes the question and file versions. Follow progress and approval requests in the shared conversation.

In Meta-Harness v1, what information about earlier candidates can the proposer access? How do the authors separate search feedback from held-out evaluation? Cite the source for each part and identify anything the evidence leaves open.

Look for separate citations about candidate history and evaluation setup, plus any unresolved gaps. If the answer misses one part, narrow it to the terms used in the paper. Confirm that you may share the selected material with your provider before sending.

What happened in this run. The release offered 6.2 Sol, which the service rejected for this Codex ChatGPT login. If this happens, choose a model your account supports from the menu beside the composer and resend. The test began reading the paper after switching to 5.6 Sol.

Check citations, revise comparisons, and export

  1. Return to the Paper library, open Research results in its sidebar, and select the question. Check for Report saved. If you only see a chat reply, check here whether there is a saved report.
  2. Select a citation. A PDF citation opens the saved version used for the study and locates the passage. If Citation evidence lists multiple matches, open each one and find the occurrence that supports or qualifies the claim. Read the context and check conditions and units.
  3. When the report has an Evidence matrix, check the comparison definition, value, and citation in each cell. Use Edit cell and record a reason when making a correction. Paper preserves the original report and records human corrections separately.
  4. Use Export Markdown to share a readable report, or Export JSON to retain structured citations, input versions, and matrix revisions. Print / PDF creates a readable copy. Reopening a saved report needs no model call.

Expected result. In this run, 5.6 Sol saved a report with three sections and 13 evidence entries. The first numbered citation opened 4 / 26 and highlighted the methods passage on page 4. After restarting the release, we reopened that report and downloaded both Markdown and JSON. Both files preserved the title, and the JSON also contained sections, source passages, and source metadata. The app continued to show Conclusions not verified.

An exact match locates the quote in the saved source. For scientific review, judge whether the passage supports the claim, whether other evidence conflicts, and whether an independent check is needed. The Fisher worked example shows independent numerical verification and evidence handoff.

Resume an unfinished study or follow up

The study ended before submitting a report
Open its research record to check Findings and Still to check. Choose Continue research to proceed from the saved evidence and gaps. Check the original conversation for requests that are still running.
The report is saved and you need one more piece of evidence
Choose Continue from here, review the draft, and send it. For example, ask for the passage in the evaluation section that describes the held-out data. The new question retrieves its own source evidence and uses previous replies as conversation context.
The question or set of papers has changed
Prepare a new research input. Compare sources and gaps across the retained records. If you import a newer PDF, the earlier report still points to the version used in that study.

The example paper has been exercised in a real Agent and desktop run. The verification record also lists what the broad first question missed. Example verification and retrieval scope

Plan a bounded literature investigation

Use Autonomous research to screen and read sources over multiple rounds around one question. It requires a configured built-in Pero Agent and an available workspace.

  1. Choose New plan and select one to five saved starting papers. Set the scope and screening criteria. For example, include original sources that describe evaluation conditions and track abstract-only candidates separately.
  2. Choose Sources to read. Begin with Saved sources only to bound the source set. When you need new sources, choose public PDFs or the policy that also permits fixed-version official HTML, as available in your version.
  3. Review rounds, searches, reading steps, model requests, and the time limit. Choose Save and review plan, then explicitly choose Start research. Review round reports, sources, and Open questions.
  4. Pausing lets you resume the same Run with the allowances already used. If the deadline passes, the allowance runs out, or you stop the study, review the retained evidence before starting any new plan.

Round reports remain Needs review. Distinguish source passages actually read from discovered candidates and failed acquisitions. Workflow limits bound operations. Provider records determine model costs. Autonomous research verification

Troubleshoot reading and research

Import fails or the PDF will not open
Confirm the file is a PDF. Uploads accept up to 16 MiB and documents up to 500 pages. If the error names missing PDF dependencies, return to environment preparation, check the installation result, and reopen the paper.
You can see the page but cannot select text
Check for a text layer with Page text. For a scan, preserve the source location with Capture area or import a copy with a text layer. Full-text search does not automatically OCR scanned PDFs.
A full-text question found no passages
Confirm the PDF is saved and the target version contains source text. Try a method name, table name, or other source-language wording. You can also discuss a passage selected by hand. No matches means the search returned no matching passages for this attempt.
A request is waiting or a report cannot be saved
Check the shared conversation for sign-in, approval, and model errors. Then open the research record to check what was saved. If validation reports invalid citations, revisit those sources before retrying. Continue from an existing unfinished record when available.
