Pero documentation

Read papers, inspect data, and record your research in one desktop workbench. Trace results back to their sources and recorded runs.

Watch the Pero introduction on Bilibili for a walkthrough of Pero and its architecture built around pluggable research Apps.

Start here

  • Install and launchChoose a desktop package for your system, verify the download, and prepare your first App. Build from source to try newer features.
  • Paper researchImport, annotate, and search a public PDF, then send a focused question to an Agent. Use the saved report to check citations, record gaps, and export evidence.
  • Research workflowsStart with a dataset, a published result, or a set of trials. Check the inputs, method, and execution evidence, then save the records someone will need to review.
  • Agents and toolsConnect a built-in or external Agent, confirm a plain-text reply, then add a workspace, context, and tool access for your task.

Choose where to run Pero

Follow the tutorials in the Electron desktop workbench. You can read and annotate PDFs, inspect local data, and save notes on your computer. Configure a model provider when you want an Agent to analyze something. Set up a Compute connection when a method needs to run on another machine.

The interactive website demo shows task assignment and result review with example data and simulated roles. The browser workbench preview shows the interface. Local Agents and research Apps require the desktop Host.

Continue by research task

  • Use Data and six sample records to import a file, filter rows, save a view, and check a version.
  • Use Notebook to save a revision with your observations and sources, then reopen or export it.
  • Use Projects to record a goal and link existing papers, research reports, and experiments.
  • Use Compute to identify the dependencies and execution location, then inspect the job status, logs, and artifacts.
  • Assess what a result supports by checking sources, run records, independent verification, and researcher review.
