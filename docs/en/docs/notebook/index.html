Record methods and reviewable evidence

Save text, formulas, and evidence references in a Notebook revision. Try a small calculation, then attach a paper citation or experiment record beside a finding.

On this page

  • Create your first notebook revision
  • Put the finding beside its source
  • Choose the right export format
  • Build a manuscript from a saved revision

Create your first notebook revision

  1. Enable and open Notebook from the workbench App Store. Choose New notebook, enter a title such as Spreadsheet and revision practice, and write down the input 2 and multiplier 6.
  2. Choose Insert → Spreadsheet. Type 2 in A1 and =A1*6 in B1. Select another cell to commit. B1 should show 12. Select it again to inspect the formula.
  3. Choose Save revision and note the revision number. Change A1 to 3 and save again. Expect a higher revision number and B1 = 18.
  4. Open File → Revision history and choose the earlier revision. Check A1 = 2 and B1 = 12. Choose Return to current notebook and verify that the current value is 18. Reopen the notebook to return to the saved revision.

If saving conflicts with another edit, choose Export draft to preserve your changes before reviewing the latest revision. Loading the latest revision discards the current draft.

Put the finding beside its source

  1. Write a specific finding and identify its metric, data scope, units, and uncertainty.
  2. Insert an Evidence block. Paste a saved Paper citation or passage link, or import a Paper report JSON, choose the citation, and attach its snapshot. Expect an excerpt with the report or location identity.
  3. For an experiment, export evidence JSON from Control Lab. Insert an Experiment reference in Notebook, load the JSON, choose the specific trial, and attach a snapshot. Open the original App to inspect that attempt’s inputs, result, and checks.
  4. Save the revision. Review the notebook revision, source version, and original evidence together. If the source App adds results, earlier Notebook revisions still show the snapshots they saved.

Notebook stores the version and evidence you selected. The source App holds the computation, source updates, and verification. Use the citation review workflow to check key claims.

Choose the right export format

  • For the complete document, choose File → Export current JSON. It retains the Notebook document and versioned evidence. For an exact historical snapshot, open that revision before exporting. Exporting the current notebook can include unsaved edits.
  • Use Markdown to share the prose. For worksheet values and formulas, choose Export workbook. XLSX preserves worksheet names, values, and formulas. Notebook evidence, charts, and original workbook formatting fall outside that exchange.
  • For Agent review, save a revision first and choose File → Ask Agent. Check the attached entry and revision before sending. Review its conclusions against that revision and the original evidence.

A worksheet supports up to 200 rows and 50 columns, scalar formulas, and references across sheets in the same notebook. External workbook links, network functions, and dynamic array spilling are outside the supported subset. See the format documentation and the workbench verification record.

Build a manuscript from a saved revision

The current source build can compile a saved MyST project to PDF. The November 12, 2026 preview predates this command. Start with a MyST manuscript, a working Tectonic engine, and a prepared package cache. Save the revision containing the manuscript block and choose Compile saved revision to PDF from that block. Check the exact revision, log, and output in build history before previewing or downloading.

After editing data or generating code, regenerate stale figures and update the document before you save a new revision. Failed builds retain inputs and diagnostics. The last successful PDF remains available in history. PDF compilation confirms the manuscript renders. Scientific claims require their own review. Follow the Fisher manuscript example with commands and expected output.
