Install and launch

Download the Electron development preview for your operating system, or launch a build from source.

On this page

  • Download the desktop workbench
  • Prepare the App environment
  • Launch from source

Download the desktop workbench

Open GitHub Releases and read the notes and assets for your release. The November 12, 2026 development preview provides these Electron packages.

  • macOS Apple Silicon. Open Pero-macos-arm64.dmg, drag Pero.app into Applications, and open it from there.
  • Windows x64. Extract Pero-windows-x64.zip in full, then open Pero.exe from the extracted folder.
  • Linux x64. Extract Pero-linux-x64.tar.gz and run ./pero in the extracted app folder. Your system needs the usual Electron desktop libraries.

macOS packages are ad-hoc signed and unnotarized. Windows and Linux packages are unsigned. Check the archive against SHA256SUMS from the same release. If the operating system blocks launch, consult the release notes.

The same preview offers Pero Native for Apple Silicon with a separate profile. This guide uses the Electron workbench for first use. Consult your release notes for features available in the package you downloaded.

Prepare the App environment

  1. Open Pero and select Papers in the sidebar. If prompted, choose Prepare environment.
  2. Wait for the environment to report ready. First-time setup may need internet access to download uv, CPython 3.12, and pinned App dependencies. If preparation fails, review the error details before retrying.
  3. Continue to read and annotate your first paper. Importing and reading a local PDF requires no model account or API key.

See Python environment settings for pre-provisioned virtual environments and offline setup.

Launch from source

Follow the development guide for Node.js, Go, Rust with the Wasm target, Electron, and the pinned GPUI Kit. Then run this command at the repository root.

npm run dev:paper

The command builds and opens Paper in a separate development profile. Use npm run dev to open the full workbench. Local reading and App computation require neither the separate Go control plane nor PostgreSQL.
