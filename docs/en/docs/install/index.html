Install and launch

Choose a desktop package for your system, verify the download, and prepare your first App. Build from source to try newer features.

On this page

Choose a release and desktop package

Open the development preview you want on GitHub Releases. The filenames below are from the November 12, 2026 preview. Features marked as current source may be newer than your package. Consult its release notes.

PlatformElectron workbenchHow to launch
macOS Apple SiliconPero-macos-arm64.dmgOpen the DMG, drag Pero.app to Applications, and launch it from there.
Windows x64Pero-windows-x64.zipExtract the whole archive into one directory, then open Pero.exe.
Linux x64Pero-linux-x64.tar.gzExtract the archive and run ./pero in the app directory. Your system needs the Electron desktop libraries.

The same release offers a separate Native package for macOS Apple Silicon. Electron and Native use separate profiles. This guide uses Electron for first launch. The macOS packages are ad-hoc signed and unnotarized. Windows and Linux development packages are unsigned. If your system blocks launch, verify the download source and consult the release notes.

Verify the downloaded file

Download SHA256SUMS from the same release. Run the command for your system from the download directory. Compare the full digest with the entry for the same archive filename.

# macOS
shasum -a 256 Pero-macos-arm64.dmg

# Windows PowerShell
Get-FileHash .\Pero-windows-x64.zip -Algorithm SHA256

# Linux
sha256sum Pero-linux-x64.tar.gz

If the digests match, continue with extraction or installation. If they differ, download the file again from the release and verify it. The build metadata identifies the source commit and target platform.

Launch and prepare the first App

  1. Open the Electron workbench and choose Papers in the sidebar. If the App reports a missing environment, choose Prepare environment.
  2. First-time preparation may download uv, CPython 3.12, and the App’s pinned dependencies. Wait for the environment to report ready. The default directory in a fresh profile is ~/.pero/environment/pero-python312. An existing profile keeps its selected environment.
  3. Open a selectable-text PDF and save a highlight to check that the reader works and saves annotations. Follow the first paper tutorial. Importing and reading a local PDF requires no model account, Task Center login, or PostgreSQL.

For offline use, follow the pre-provisioned environment instructions to configure an absolute venv directory with its dependencies installed. See Compute and environments for preparation, inspection, and binding.

Diagnose launch and preparation failures

The application window never opens
Check the download digest, CPU architecture, and folder contents. On Linux, match any reported missing shared libraries to your distribution’s runtime dependencies.
The workbench opens but an App reports a missing environment
Start preparation from the App prompt. If it fails, read the details to distinguish a failed download, an invalid existing environment, and a failed App startup. Reopen the App once the environment reports ready.
An App, record, or setting appears to be missing
Confirm that you opened the intended Electron, Native, or development profile and that the feature shipped in your version. See the profile and data locations.
Preparation succeeded but the App still fails
In recent source builds, look for app-startup.jsonl next to the Host settings. Match the request ID from the interface to the startup stage, error code, and exit status. Include the shareable record if you file an issue.

Launch from source

Check the system prerequisites in the development guide. Current source uses Node.js 22.18+, Go 1.27.3, Rust stable, the Wasm target of nightly-2026-10-28, and a pinned GPUI Kit checkout. Run these POSIX shell commands from a clean Pero checkout, with no gpui-kit directory already beside it.

npm ci
node node_modules/electron/install.js
rustup toolchain install stable --profile minimal
rustup toolchain install nightly-2026-10-28 --profile minimal --target wasm32-unknown-unknown
git -c core.autocrlf=false clone https://github.com/longbridge/gpui-kit.git ../gpui-kit
git -C ../gpui-kit checkout --detach 7591a35eced761e3613c01e71ff04c10129dae1a
export PERO_GPUI_KIT_PATH="$(cd ../gpui-kit && pwd)"
npm run dev

The first build may download Rust dependencies, fonts, Wasm tooling, and App dependencies. A successful build opens the Electron workbench. Use npm run dev:paper to try Paper in a separate profile. Use npm start to open existing workbench outputs after a build.
