From a dataset to a research notebook

Download six synthetic records, check fields and duplicates in Data, and save a view for the treatment group. Record your method, calculations, or conclusions separately in Notebook. When handing off your work, record the asset version and SHA-256 and include the original or an accessible source.

  • Follow the six-record Data walkthrough.
  • Save your first Notebook revision or attach evidence someone can trace.

Recheck one number from Fisher Table III

This walkthrough rechecks the sepal-length within-species sum of squares of 19.1434 cm² from Fisher (1936), Table III. Table I supplies 100 inputs, 50 each for setosa and versicolor. For each species, sum the squared deviations from its mean and add the two sums. The table reports 98 degrees of freedom. The sum of squares has no divisor.

  1. Download the original university-hosted PDF and import it into Paper. In the reader, choose Select Fisher Table III result. This opens the original cell on PDF page 4 (printed page 181). The action requires the original file’s SHA-256, so use the download without printing or resaving it.
  2. Open Review input observations and compare the inputs with Table I on PDF page 3 (printed page 180). Setosa row 32 reads 5.4 in the scan. Text recognition may return 6.4. Keep the default absolute tolerance 0.00005, confirm the inputs, statistic, and policy, then choose Freeze protocol.
  3. Choose Confirm and run fixed arithmetic. Open that attempt and review execution status, the single-result verdict, the independent check, and the original location. The recorded group sums are 6.0882 and 13.0552. The independent exact total is 95717/5000, with a difference of 0 cm² from the published value.
  4. Choose Export standalone handoff ZIP and extract it into a fresh directory. The ZIP includes the original PDF, reviewed CSV, frozen protocol, execution records, and standalone verifier. Run the command below in that directory. The check requires only the Python standard library and works offline.
python -I -S verify.py

Expect exit code 0 and JSON with count: 100, exact numerator 95717, denominator 5000, single-result verdict REPRODUCED, and whole-paper status NOT_ASSESSED. If the environment differs from the frozen protocol, review the logs and restore it, or review the new environment and freeze a new protocol. A completed calculation outside tolerance calls for reviewing the inputs and policy. A rerun uses the same policy and keeps a separate attempt.

See the Fisher verification record for source digests, observed runs, and recovery evidence.

Organize materials around a research question

Write the question in a research project and link the relevant Paper documents, research records, or experiments. The project shows a summary and opens the record in its source App. To cite an exact input in a report, retain the paper version, Notebook revision, or trial ID as well.

From candidate search to independent trials

Control Lab uses python-control for controller simulation and ngspice for a constrained second-order active low-pass simulation. Check the availability panel for the actual solver before starting. Install ngspice through your system and make its executable available on the desktop process’s PATH.

  1. Freeze the system, inputs, metrics, search scenarios, and acceptance thresholds.
  2. Run the bounded search. Compare the baseline and candidate traces and record why you chose a candidate.
  3. Lock that candidate and run the final scenarios. Check results, units, constraints, and any failures. Use Export to get the experiment JSON and attach a specific trial to a notebook.

Interpret finite-window observations against the frozen criteria. Hardware performance, asymptotic stability, and formal acceptance require their own evidence. See Control Lab environment and verification requirements.

Prepare a remote run

Use an authorized SSH or Slurm environment to try the built-in CPU midpoint quadrature. Review the connection, fixed parameters, and resources before submitting. Then check the status, logs, and collected artifacts for that attempt. Follow the environments and remote compute guide.
