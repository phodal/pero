## External boundaries and truthful outcomes

Configured live-model execution requires an available Host model/session. Canvas and project operations require the actual installed owners and Host responses. Existing owner wiring is implementation work, not automatically an external blocker. Undefined provider file-list/download/sync contracts need a concrete integration design, not invented receipts.

Authenticated identity/reviewer decisions, compliant signatures, notification delivery, remote registry commits, inventory deductions and instrument runs require their real service or hardware owners. Persisted local records cannot attest to those events. Reference tenant credentials are not needed to implement original local equivalents. Unknown reference licensing prohibits copying source/assets, not capability implementation.
