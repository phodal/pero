概念与参考

了解数据和执行由谁管理，以及怎样核对功能在什么版本、平台和条件下通过了验证。

工作台中的对象

研究项目
保存研究目标和 App 记录引用，可按需关联本地目录。
App
提供一个领域的界面、方法与数据，例如 Paper 保存论文与研究报告，Data 保存数据版本。
Host 与 Agent 会话
Host 管理本机 App、凭据以及 Agent 的会话、审批和取消。使用工具前，可在对话里查看待审批的请求。
控制面与 Worker
可选控制面协调共享任务，独立 Worker 在所配置的执行环境中处理任务。相关服务需要单独部署和授权。

完整的职责与接入状态见架构文档和 App 开发说明。

数据、权限与费用

  • App 领域数据保存在运行它的机器上。调用模型、文献检索、MCP 连接器或共享任务服务时，相应外部服务可能收到选定的数据。
  • 本地插件和 App 后端运行受信任的代码。打开敏感材料前，检查安装来源、会话权限和提交的内容。
  • 模型和远程算力由各自的提供方计费。费用以提供方记录为准，研究操作次数或运行时间限制只约束工作流。

验证范围与问题反馈

质量门禁记录各项功能的源码检查、真实桌面、外部服务和发布包验证。复核科学结果时，还需检查来源、运行输入、比较规则和独立验收。计划中的跨团队同步与共享研究记忆见路线图。

反馈问题时，请在 GitHub Issues 附上版本或源码提交、平台、Electron 或 Native、复现步骤和可分享的错误信息。代码贡献从贡献指南开始。
