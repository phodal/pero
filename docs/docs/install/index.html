安装与启动

选择对应系统的桌面包，校验下载，准备第一个 App 的环境。需要开发分支功能时，可以从源码启动。

选择版本和桌面包

在 GitHub Releases 打开你要安装的开发预览版。以下文件名对应 2026-11-12 开发预览版。文档中标记为源码的功能可能晚于安装包，核对时以你的版本和对应发布说明为准。

平台Electron 工作台启动方式
macOS Apple SiliconPero-macos-arm64.dmg打开 DMG，把 Pero.app 拖到「应用程序」，从那里启动。
Windows x64Pero-windows-x64.zip完整解压到同一个目录，再打开 Pero.exe。
Linux x64Pero-linux-x64.tar.gz解压后，在应用目录运行 ./pero。需要系统提供 Electron 桌面库。

同一版本还提供独立的 macOS Apple Silicon Native 包。Electron 和 Native 使用各自的配置。本文的首次启动路径以 Electron 为例。macOS 开发包采用 ad-hoc 签名且未经公证，Windows 和 Linux 开发包未签名。系统阻止启动时先核对发布说明和下载来源。

校验下载文件

从同一个发布条目下载 SHA256SUMS。在下载目录按系统运行一条命令，把输出的完整摘要与校验文件中同名归档的那行对照。

# macOS
shasum -a 256 Pero-macos-arm64.dmg

# Windows PowerShell
Get-FileHash .\Pero-windows-x64.zip -Algorithm SHA256

# Linux
sha256sum Pero-linux-x64.tar.gz

摘要一致时继续解包或安装。摘要不一致时重新从发布条目下载并校验。发布条目里的构建信息可用于核对源码提交和目标平台。

首次启动并准备 App 环境

  1. 打开 Electron 工作台。在侧栏选择论文。如果界面提示缺少运行环境，点击准备环境。
  2. 首次准备可能需要联网获取 uv、CPython 3.12 和 App 声明的固定依赖。等待界面显示环境就绪。新配置的默认环境目录为 ~/.pero/environment/pero-python312，已有配置继续使用已选环境。
  3. 打开一份可选中文字的 PDF 并保存一处高亮，验证阅读器和保存流程。按第一篇论文教程操作即可。导入和阅读本地 PDF 无需模型账号、Task Center 登录或 PostgreSQL。

需要预装依赖供离线使用时，按预置环境说明设置绝对 venv 目录。准备、检查和绑定环境的区别见计算环境。

定位启动或准备失败

应用窗口打不开
检查下载摘要、CPU 架构和解压是否完整。Linux 如果报告缺少共享库，先检查报错中的库名和对应发行版运行依赖。
工作台能打开，App 报缺少环境
从 App 提示显式准备环境。失败时打开详情，区分下载失败、已有环境无效和 App 启动失败。看到就绪后再打开 App。
预期的 App、资料或设置没有出现
确认打开的是原来的 Electron、Native 或开发预览配置，并核对当前发布版本是否包含该功能。各 App 的领域数据位置见数据与配置。
准备成功后仍启动失败
较新的源码构建可在 Host 设置文件旁查看 app-startup.jsonl，用界面的请求 ID 对照启动阶段、错误码和退出状态。报告问题时附上可分享的对应记录。

从源码启动

先核对开发指南中的系统依赖。当前源码需要 Node.js 22.18+、Go 1.27.3、Rust stable、nightly-2026-10-28 的 Wasm 目标，以及固定的 GPUI Kit。以下命令用于 POSIX shell，假设当前位于干净的 Pero 仓库根目录，且上一级没有 gpui-kit 目录。

npm ci
node node_modules/electron/install.js
rustup toolchain install stable --profile minimal
rustup toolchain install nightly-2026-10-28 --profile minimal --target wasm32-unknown-unknown
git -c core.autocrlf=false clone https://github.com/longbridge/gpui-kit.git ../gpui-kit
git -C ../gpui-kit checkout --detach 7591a35eced761e3613c01e71ff04c10129dae1a
export PERO_GPUI_KIT_PATH="$(cd ../gpui-kit && pwd)"
npm run dev

首次构建可能下载 Rust 依赖、字体、Wasm 工具和 App 依赖。成功时会打开 Electron 工作台。只想试 Paper 可运行 npm run dev:paper，它使用独立配置。构建过且无需重建时，可用 npm start 打开现有工作台产物。
