安装与启动

选择适合操作系统的 Electron 开发预览版，或按开发指南从源码启动。

本页目录

  • 下载桌面版
  • 准备 App 环境
  • 从源码启动

下载桌面版

打开 GitHub Releases，查看所选版本的说明和下载文件。下面的包名对应 2026-11-12 Electron 开发预览版。

  • macOS Apple Silicon。打开 Pero-macos-arm64.dmg，将 Pero.app 拖入「应用程序」，然后从那里打开。
  • Windows x64。完整解压 Pero-windows-x64.zip，打开解压目录中的 Pero.exe。
  • Linux x64。解压 Pero-linux-x64.tar.gz，在解压后的程序目录运行 ./pero。系统需提供 Electron 所需的桌面库。

macOS 包使用 ad-hoc 签名，尚未经公证。Windows 和 Linux 包未签名。下载后可用同一版本的 SHA256SUMS 核对文件摘要。如遇系统启动限制，请查看发布说明。

同一版本还提供 macOS Apple Silicon 的 Pero Native，使用独立配置。文档里的首次体验以 Electron 工作台为准。源码文档中的功能可能晚于你下载的版本，具体以该版本的说明为准。

准备 App 环境

  1. 打开 Pero，在侧栏选择论文。遇到环境提示时，选择准备环境。
  2. 等待环境已就绪。首次准备可能需要联网下载 uv、CPython 3.12 和 App 的固定依赖。失败时先查看错误详情，再重试。
  3. 准备完成后，继续阅读并标注第一篇论文。导入和阅读本地 PDF 无需模型账号或 API Key。

已准备好的虚拟环境和离线使用见 Python 环境设置。

从源码启动

先按开发指南准备 Node.js、Go、Rust（含 Wasm 目标）、Electron 和固定版本的 GPUI Kit，再在仓库根目录执行下面的命令。

npm run dev:paper

这个命令构建并启动独立开发配置中的 Paper。打开完整工作台用 npm run dev。本地阅读和 App 计算无需启动独立的 Go 控制面或 PostgreSQL。
