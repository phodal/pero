Pero 文档

在同一个桌面工作台阅读论文、检查数据、记录研究过程，并回到原文和运行记录复核结果。

从这里开始

  • 安装与启动选择对应系统的桌面包，校验下载，准备第一个 App 的环境。需要开发分支功能时，可以从源码启动。
  • 论文阅读与研究用一篇公开 PDF 练习导入、标注和本地检索，再把具体问题交给 Agent。报告保存后，逐条回查原文、记录缺口并导出证据。
  • 科研工作流从一份数据、一条论文结果或一组试验记录开始，核对输入、方法与执行证据，再把需要复查的内容保存下来。
  • Agent 与工具连接内置或外部 Agent，用一轮纯文本对话确认模型可用，再按任务添加工作目录、上下文和工具权限。

选择运行方式

跟做文档里的教程请使用 Electron 桌面工作台。阅读 PDF、标注、查看本地数据和保存笔记可在本机完成。需要让 Agent 分析时，再配置模型服务。需要在另一台机器上运行方法时，再配置计算连接。

官网交互演示可以在浏览器里体验任务分配与结果复核。演示使用预设数据和模拟角色。浏览器工作台预览可查看工作台界面，运行本地 Agent 和领域 App 需要桌面宿主。

按研究任务继续

  • 用六条合成记录练习导入、筛选、保存视图和核对版本。
  • 在研究笔记里保存一个修订，把观察和来源留在一起，再重新打开或导出。
  • 在研究项目里写下目标，关联已有论文、研究记录和实验。
  • 准备计算环境，确认依赖与运行位置，再查看作业状态、日志和产物。
  • 按证据复核步骤查看来源、运行记录、独立验证和研究者结论。
