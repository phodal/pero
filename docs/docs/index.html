Pero 文档

在桌面工作台里阅读论文、检视数据、运行科研 App，并沿着记录回查证据。第一次用 Pero，可以先导入一篇 PDF。

选择一个任务

  • 安装与启动选择适合操作系统的 Electron 开发预览版，或按开发指南从源码启动。
  • 阅读第一篇论文导入 PDF，保存一处原文标注。需要进一步分析时，再发送问题并逐条回查回答中的引用。
  • 科研工作流检视一个数据版本、复核一个已发表的数值，或用研究项目整理材料。以下功能以相应源码版本和验证记录为准。
  • 概念与参考了解数据和执行由谁管理，以及怎样核对功能在什么版本、平台和条件下通过了验证。

选择运行方式

Electron 桌面版适合从自己的论文和数据开始。阅读原文、保存标注和检视数据均可在本机完成；需要 Agent 时再配置模型服务。

官网交互演示可直接在浏览器里体验任务分配与结果复核。演示使用预设数据和模拟角色；跟随本文档的研究步骤请使用桌面工作台。
