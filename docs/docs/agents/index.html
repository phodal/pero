配置 Agent 与工具

连接内置或外部 Agent，用一轮纯文本对话确认模型可用，再按任务添加工作目录、上下文和工具权限。

配置内置 Pero Agent

  1. 打开 设置 → 内置 Agent。填写服务商提供的 API 地址、模型和 API Key。内置 Agent 的默认地址是 https://api.deepseek.com，默认模型是 deepseek-chat。地址使用 HTTPS，本机回环服务可用 HTTP。模型字段填写模型 ID。
  2. 点击保存，确认显示已保存。桌面版使用系统凭据存储加密密钥。以后修改地址或模型时，密钥留空可保留已保存的值。需要清除时，点击移除已保存密钥再确认。
  3. 打开新聊天，在输入框附近选择 Pero (DeepSeek)。新会话使用刚保存的配置。

界面保存的配置优先于开发环境中的 DEEPSEEK_* 变量或 .env。已有会话继续使用创建时的配置。源码启动方式及配置目录见安装与启动和 桌面配置说明。

连接外部 Agent

Pero 用本地 ACP 适配器连接外部 Agent。设置 → 模型与 Agent可查看适配器是否可用。各 Agent 使用自己的登录和模型配置。

Codex、Claude
Electron 开发预览包装有这两个 ACP 适配器。从源码运行时，根目录的 npm ci 安装项目所用的适配器。按会话提示完成各自的登录方式，再选择该 Agent 提供的模型。
GitHub Copilot、Grok、Qoder、OpenCode
需要分别安装支持 ACP 的本地 CLI，并完成对应的登录或服务商配置。当前登记的可执行程序为 copilot、xAI 的 grok-build 或其安装目录中的 grok、qodercli 和 opencode。安装后重启 Pero 再检查选择器。

若提示请先在终端登录，完成该 Agent 的终端登录，回到会话点已登录，继续。其他登录方式按 Agent 显示的按钮操作。完成登录后，检查原问题并手动重发。

跑通第一轮对话

  1. 打开新聊天。通过输入区的文件夹按钮选择一个空的练习目录，再选已配置的 Agent。工作目录是该会话的本机执行目标，开始实际对话后如需切换目录或 Agent，请新建会话。
  2. 先发送一条无需工具和附件的短消息。若界面出现登录提示，按上节处理后手动重发。

请只回复 PERO_SETUP_OK。这次无需调用工具、读取或修改文件。

收到约定文本即完成模型往返。已安装只说明适配器已找到，成功连接 ACP 也可能先于模型登录。模型回应后，可用论文选段问答进一步验证该 Agent 是否适用于科研任务。

检查工作目录和审批范围

从专用目录开始。在输入框的上下文菜单选择需发送的文件，发送前检查草稿及引用。目录给本机 Agent 提供工具工作的基准，发送的内容以及后续工具读取结果可能进入所用模型服务。

  • 权限菜单按 Agent 能力显示。内置 Agent 提供仅可查看时，读取工作区可用，文件修改和命令会被拒绝。工作区内修改对写入要求确认，命令仍被拒绝。
  • 完全权限下文件修改和命令会请求确认，自动审查会自动放行。内置 Agent 这些模式下的命令没有操作系统级沙箱。各平台及外部 Agent 可能提供不同的权限模式。
  • 出现需要你的授权时，展开相关工具，核对动作和目标。仅为当前动作授予一次权限（若 Agent 提供该选项），或拒绝并重新描述任务。可点停止请求结束活动回合，已完成的外部操作需到原系统核查。

添加 MCP 工具和连接器

  1. 在工作台打开连接器，也可从应用目录打开。选择可信服务，按该项的配置表单保存并完成登录。若出现浏览器授权，核对账号与范围。凭据只填在连接器提供的专用字段，避免写进 URL、参数、配置示例或对话。
  2. 点击验证连接。显示验证通过时，服务完成了工具发现，验证连接随即释放。查看工具列表，勾选本次工作需要的工具并保存。目录卡片与已启用工具的实际能力以当前连接结果为准。
  3. 新建对话后使用该连接。Host 为每个会话固定当时的连接配置和工具许可。修改凭据或授权会让旧的连接器快照失效。完成变更后，在新会话用该服务文档中的只读操作验证结果。

独立的每 Agent MCP 配置依赖适配器支持，与上面的连接器目录各自保存。全文检索等能力需要 Agent 支持相应 MCP 传输。工作台的连接器运行时面向 macOS 和 Linux，在 Windows 上会提示平台不受支持。更多见连接器设计与平台验证记录。

排查登录、模型和工具问题

Agent 显示未安装或选择器中不可选
检查 CLI 或适配器是否安装在桌面进程能找到的位置，重启 Pero，再选择一次。
内置 Agent 需要 API Key，或设置保存失败
确认地址、模型 ID 以及密钥来自同一服务。若提示系统凭据存储不可用，先解锁系统凭据存储，重新打开 Desktop 并保存，再建会话试一次。
连接成功但模型拒绝请求
用该 Agent 的登录方式处理鉴权错误。若界面提供模型选择器，选账号有权限访问的模型。先用上面的纯文本提示确认模型回复，再添加工具。
工具不可用或调用被拒绝
先检查该连接的验证结果、工具是否被勾选，以及会话权限和 Agent 的传输支持。配置修改后新开会话。外部写入的结果若不明确，先核对原服务的操作记录再决定是否重复执行。

记录软件包版本、Agent 名称、可分享的错误消息与复现步骤。提交问题与核对验证范围。
