从数据到研究笔记

下载六条合成记录，在 Data 中检查字段与重复行，筛选处理组并保存视图。接着在 Notebook 中另存你的方法、计算或结论。若要交接，记下数据版本与 SHA-256，并随笔记提供原始文件或可访问的来源。

  • 跟做六条记录的数据检视与绘图。
  • 跟做第一条笔记修订，或保存一条可回查的证据。

复核 Fisher 表 III 的一个数值

下面复核 Fisher（1936）表 III 的萼片长度组内平方和 19.1434 cm²。输入是表 I 的 100 个观测值，setosa 和 versicolor 各 50 个。按物种分别求均值与离均差平方和，再加总两组。自由度 98 用于解释表格，这项统计量不除以 98。

  1. 将这份大学托管的原始 PDF下载并导入 Paper。打开阅读器，点击选择 Fisher 表 III 结果，应跳到 PDF 第 4 页（印刷页 181）的原始单元格。按钮依赖原始文件的 SHA-256，重新打印或重存的 PDF 会失去匹配。
  2. 展开核对输入观测值，与 PDF 第 3 页（印刷页 180）的表 I 对照。扫描中 setosa 第 32 行是 5.4，文字识别可能得到 6.4。保留页面给出的默认绝对容差 0.00005，核对数据、统计口径与比较规则后点击冻结方案。
  3. 点击确认并运行固定算术。选中本次尝试，检查执行状态、单个结果判定、独立数值核验和原文位置。历史验收的两组平方和为 6.0882、13.0552，独立精确总和 95717/5000，与论文值相差 0 cm²。
  4. 点击导出独立交接 ZIP，解压到新目录。ZIP 含原始 PDF、人工核对的 CSV、冻结方案、运行记录和独立核验器。在解压目录执行下方命令。此检查只需要 Python 标准库，无需联网或模型账号。
python -I -S verify.py

预期退出码为 0。核验 JSON 应有 count: 100，精确结果的分子和分母分别为 95717 与 5000，单项判定为 REPRODUCED，整篇论文状态为 NOT_ASSESSED。如果运行环境与冻结方案不符，查看日志后恢复环境，或核对新环境并建立新方案。若计算完成却未满足容差，先核对输入与规则。重跑沿用同一规则并保存一条新的尝试记录。

完整源文件摘要、实际执行与恢复证据见 Fisher 案例验证记录。

让研究材料回到同一个问题

在研究项目中写下待回答的问题，关联 Paper 论文、研究记录或实验。项目中显示的是原记录的摘要；打开时回到原 App。需要在报告中引用精确输入时，继续保留论文版本、Notebook 修订或试验编号。

从候选方案到独立试验

控制实验支持用 python-control 做控制器仿真，或用 ngspice 做限定的二阶有源低通仿真。打开实验前，先确认可用性面板显示实际求解器。ngspice 需要系统安装并能从桌面进程的 PATH 找到。

  1. 冻结系统、输入、指标、搜索场景和验收阈值。
  2. 运行有界候选搜索，对比基线与候选曲线，记录候选方案为何被选中。
  3. 锁定候选并运行最终场景，逐项检查结果、单位、约束和失败项。从实验的导出获取 JSON，把具体试验记录附进笔记。

有限采样窗内的结果需要按冻结规则解释。实物电路、无限时间稳定性和正式验收仍需各自证据。查看 Control Lab 的环境要求和验证边界。

准备一次远程计算

已获授权的 SSH 或 Slurm 环境可用于尝试内置 CPU 中点求积。提交前检查连接、固定参数和资源，提交后用同一次尝试的状态、日志和已收集产物核对结果。查看环境与远程计算的完整流程。
