科研工作流

检视一个数据版本、复核一个已发表的数值，或用研究项目整理材料。以下功能以相应源码版本和验证记录为准。

检视一个数据版本

  1. 将六条合成记录保存为 first-dataset.json。在数据中选择导入数据，选择文件并确认导入。
  2. 打开该数据集并选择查看数据，确认有 6 条记录和 3 个字段。在来源信息中核对所选版本和 SHA-256。
  3. 需要记录筛选或图表设置时，保存视图。更新数据时，用已有条目的添加版本追加文件。在资料库再次导入同名文件会创建新条目。

表格检视可以在本机完成，无需模型。支持 UTF-8 CSV、TSV、JSON 和 JSONL，导入上限为 10 MiB。详见 Data 版本、来源与检查规则。

复核 Fisher 论文中的一个数值

  1. 在 Paper 导入项目复核使用的 Fisher（1936）原始 PDF。匹配该文件后，工具栏会提供 Fisher Table III 的结果选择入口。
  2. 查看原表、100 条输入测量值、计算方法和比较规则。冻结协议后，显式确认并运行一次。对照原文中的 19.1434 cm²、计算值、差值和独立数值检查。
  3. 导出证据 ZIP 并解压，在解压目录运行下方命令。独立检查只使用 Python 标准库，无需联网或调用模型。
python -I -S verify.py

记录中的 REPRODUCED 对应该表的单个数值。整篇论文仍为 NOT_ASSESSED（未评估）。查看 Fisher 案例的输入与验收记录。

把材料关联到研究项目

选择新建研究项目，填入项目名称和研究目标，可以按需关联本地目录。打开资料与实验 → 关联已有记录，选择已启用的 App，再关联保存的论文、研究记录或实验。

项目保存指向原记录的引用。之后从项目打开材料时，仍由对应 App 展示。若原记录版本有变化，可查看原记录后更新关联。详见研究项目的功能与验证。

准备一次远程计算

有已授权的 SSH 或 Slurm 环境时，可在科学计算中选择连接，探测后准备内置的 CPU 中点求积方法。检查目标、固定参数和所需资源后，再显式批准提交。

用原尝试查看状态与日志，收集已保存的产物。当前验证覆盖实际 SSH 回环和 Slurm 测试替身。真实 Slurm 站点和其他科研方法需分别验收。入口和限制见 Compute 使用说明和验证记录。
