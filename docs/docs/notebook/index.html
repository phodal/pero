记录方法与可复查的证据

用笔记修订保存正文、表格公式和证据引用。先完成一个小算例，再把论文引用或试验记录附到结论旁。

创建第一条笔记修订

  1. 从工作台应用商店启用并打开 Notebook，选择新建笔记。填入标题 表格与修订练习，在正文记下输入 2 和乘数 6。
  2. 选择插入 → 电子表格。在 A1 输入 2，在 B1 输入 =A1*6，点击其他单元格以提交。B1 应显示 12，再次选中它可以检查公式。
  3. 点保存新修订，记下工具栏上的修订号。再把 A1 改成 3 并保存，应看到更高的修订号和 B1 = 18。
  4. 打开文件 → 修订历史，选中前一条修订，核对 A1 = 2、B1 = 12。点击返回当前笔记，确认当前是 18。关闭再打开笔记，应能回到已保存的修订。

如果保存冲突，先用导出草稿保留自己的版本，再查看已保存的最新修订后整理差异。加载最新修订会放弃当前草稿。

把结论与原始记录放在一起

  1. 在笔记写下一个具体发现，标明指标、数据范围、单位和不确定性。
  2. 插入证据块。可粘贴已保存的 Paper 引用或段落链接。也可导入 Paper 报告 JSON，选择具体引用，然后附加快照。此处应保留原文摘录和对应的报告或位置标识。
  3. 若要记录试验，在 Control Lab 导出证据 JSON。在 Notebook 插入实验引用，导入该 JSON，选择具体试验并附加快照。打开原 App 核对该尝试的输入、结果与检查。
  4. 保存新修订。审阅时对照开发工作台中记录的笔记修订、来源版本和原文。原 App 新增结果后，历史笔记修订中的快照仍保持保存时的内容。

笔记保存研究者选定的版本和证据，求解、来源更新与验证由原 App 持有。追问或复查时，可按原文回查的方式核对关键主张。

选对交付格式

  • 完整交接选择文件 → 导出当前 JSON，保留笔记文档和版本化证据。需要交付确切的历史内容时，先打开相应修订再导出。当前笔记的普通导出可包含尚未保存的改动。
  • 交流正文可用 Markdown。需要在电子表格里继续使用数据与公式时，使用导出工作簿。XLSX 保留工作表、值和公式；笔记证据、图表及原书样式不在此交换范围内。
  • 若要请 Agent 审阅，先保存修订，再选文件 → 询问 Agent。确认草稿所附条目与修订号，随后发送。结果中的判断应回到保存版本和原证据核对。

工作表每页上限为 200 行、50 列，支持标量公式和同一笔记内的跨工作表引用。外部工作簿链接、网络函数和动态数组溢出不在支持范围内。详情见 Notebook 格式说明与工作台验证记录。

从已保存修订编译文稿

当前源码支持将已保存的 MyST 项目编译为 PDF。2026-11-12 的开发预览包发布时尚无该编译入口。需要已有的 MyST 文稿、可用的 Tectonic 引擎及预备好的包缓存。先保存包含文稿块的修订，在该块选将已保存修订编译为 PDF。在构建历史中检查确切修订号、编译日志和输出，再预览或下载。

修改数据或生成代码后，先重新生成并更新过期图件，再保存新修订。失败记录保留诊断和输入，上一份成功 PDF 仍可在历史中打开。编译成功只说明文稿能生成 PDF，科学结论依然需要复核。可跟做带编译命令和预期结果的 Fisher 文稿示例。
