记录方法与可复查的证据

用笔记修订保存正文、表格公式和证据引用。先完成一个小算例，再把论文引用或试验记录附到结论旁。

创建第一条笔记修订

以下步骤在 Apple Silicon macOS 上，使用 2026-11-12 Electron 预览包及全新配置验证。

  1. 在工作台侧栏打开 Notebook。此预览包已经安装并启用 Notebook。首次出现环境未就绪时，点击准备环境，等待新建笔记出现。首次准备可能需要下载 Python 和依赖。如果等待过久或安装失败，先展开安装日志查看进度或错误，再决定是否重试。
  2. 选择新建笔记，填入标题 表格与修订练习，在正文记下输入 2 和乘数 6。新建笔记从修订 1开始。
  3. 选择插入 → 电子表格。在 A1 输入 2，在 B1 输入 =A1*6。点击另一个单元格提交公式，离开 B1 后应看到计算值 12。
  4. 点保存新修订，核对工具栏显示修订 2。再把 A1 改成 3，离开单元格后再次保存，核对修订 3及 B1 = 18。

打开文件 → 修订历史 → 修订 2。只读视图应显示 A1 = 2、B1 = 12。查看旧修订时，侧栏仍显示当前保存的修订号。点击返回当前笔记回到修订 3。需要基于旧内容重新编辑时，再用恢复为草稿。

要核对持久化，退出 Pero，重启后打开 Notebook 并选择已保存的笔记。实测仍为修订 3，A1 = 3、B1 = 18。

如果保存冲突，先用导出草稿保留自己的版本，再查看已保存的最新修订后整理差异。加载最新修订会放弃当前草稿。

把结论与原始记录放在一起

  1. 在笔记写下一个具体发现，标明指标、数据范围、单位和不确定性。
  2. 插入证据块。可粘贴已保存的 Paper 引用或段落链接。也可导入 Paper 报告 JSON，选择具体引用，然后附加快照。此处应保留原文摘录和对应的报告或位置标识。
  3. 若要记录试验，在 Control Lab 导出证据 JSON。在 Notebook 插入实验引用，导入该 JSON，选择具体试验并附加快照。打开原 App 核对该尝试的输入、结果与检查。
  4. 保存新修订。审阅时对照开发工作台中记录的笔记修订、来源版本和原文。原 App 新增结果后，历史笔记修订中的快照仍保持保存时的内容。

笔记保存研究者选定的版本和证据，求解、来源更新与验证由原 App 持有。追问或复查时，可按原文回查的方式核对关键主张。

选对交付格式

  • 完整交接选择文件 → 导出当前 JSON。实测 Notebook.json 中包含练习标题和原始公式 =A1*6。此格式保存文档与已记录的证据引用。需要交付准确的历史内容时，先打开相应修订再导出。导出当前笔记可包含尚未保存的改动。
  • 需要表名、数值和公式时，选文件 → 导出工作簿。发布包导出的 Notebook.xlsx 中，A1 = 3，B1 保留公式 A1*6，打开工作簿时会请求重新计算。需要笔记证据时用 JSON，交流正文可用 Markdown。
  • 需要 Agent 审阅时，先保存修订，再选文件 → 询问 Agent。实测打开的是引用已保存修订 3 的草稿。发送前核对草稿和引用，收到答复后回到保存版本及原证据复查。

要检查 JSON 导出，点新建笔记旁的…，选择导入笔记 JSON。实测导出文件生成一条独立笔记，从修订 1开始，仍是 A1 = 3、B1 = 18。原笔记仍保留在修订 3。

如果浮动对话挡住文件菜单底部，用对话标题栏的减号按钮收起对话，或者点击停靠对话。重新打开文件即可选导出工作簿。

工作表每页上限为 200 行、50 列，支持标量公式和同一笔记内的跨工作表引用。外部工作簿链接、网络函数和动态数组溢出不在支持范围内。详情见 Notebook 格式说明与工作台验证记录。

从已保存修订编译文稿

使用当前源码构建跟做 MyST 出版流程。需要已有的 MyST 文稿、可用的 Tectonic 引擎及预备好的包缓存。先保存包含文稿块的修订，在该块选将已保存修订编译为 PDF。在构建历史中检查确切修订号、编译日志和输出，再预览或下载。上面的发布包教程验证了工作簿与 JSON 导出。

修改数据或生成代码后，先重新生成并更新过期图件，再保存新修订。失败记录保留诊断和输入，上一份成功 PDF 仍可在历史中打开。编译成功只说明文稿能生成 PDF，科学结论依然需要复核。可跟做带编译命令和预期结果的 Fisher 文稿示例。
