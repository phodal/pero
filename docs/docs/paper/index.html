导入并保存标注

准备一份能选中文字的 PDF。首次打开请先完成环境准备。

  1. 打开侧栏的论文，选择添加论文 → PDF → 导入 PDF，或把文件拖进 Paper 窗口。
  2. 在阅读器选中一句原文，点击高亮。通过 PDF 的右键菜单打开标注，检查刚保存的位置和选文。
  3. 返回文库再打开这篇论文，确认标注仍能回到原页。Paper 将标注单独保存，保留导入时的原始 PDF。

这一步无需模型。选文与全文检索依赖 PDF 的文字层。若无法选中文本，可用 PDF 菜单的截取图片保留需要核对的图表位置。

用选段向 Agent 提问

  1. 使用内置 Agent 时，在设置 → 内置 Agent配置 API 地址、模型和 Key。外部 Agent 使用各自的登录方式。检索 PDF 全文需要支持 HTTP MCP 的 Agent。参见 Agent 配置说明。
  2. 在阅读器点击询问 AI，或选中文字后点击讨论选段。检查草稿和附带的选段，再主动发送。模型服务可能收到问题和选定的原文。

作者怎么描述这项方法的适用条件？请给出原文引用，并列出还需要核对的限制。

回查引用和原文

  1. 报告保存后，在阅读器工具栏点击时钟图标研究记录，打开报告。
  2. 点击一条引用，查看原文位置和上下文。有多个匹配时，选择与该条主张相关的位置。
  3. 对照主张、原文和报告里尚待核对的问题。点击从此处追问可以准备下一轮问题，再由你发送。

引用定位可帮助核对原文。主张是否得到支持、方法能否复用，仍需研究者判断。

常见卡点

  • Agent 启动或登录失败。检查所选 Agent、凭据和会话里的错误。完成登录后，检查并重发问题。
  • 全文检索没有命中。换成论文使用的术语，缩小问题范围，或在原文中选定片段。空检索结果只表示本次没有匹配。
  • 研究停在报告提交前。打开保留的研究记录，查看已有发现和待核对项，再选择继续研究。

更多阅读与检索方式见 Paper 使用说明。
